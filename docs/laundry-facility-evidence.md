# Laundry facility evidence: Illinois camp 00128

Reviewed: 2026-07-12

## Conclusion

No publicly available paperwork located in this review establishes that migrant labor camp `IL-IDPH-00128`, Fiesta Motel in Pontiac, Illinois, lacks laundry facilities. The defensible status is **not established**, not "no laundry."

## Evidence

- [Illinois Migrant Labor Camp Code Section 935.65(d)](https://www.ilga.gov/ftp/JCAR/AdminCode/077/077009350000650R.html) requires laundry facilities with hot and cold water for all occupants.
- [IDPH says it inspects every licensed migrant labor camp](https://dph.illinois.gov/topics-services/environmental-health-protection/migrant-labor.html), but the public camp roster is not an inspection report and does not contain laundry findings.
- The ETA-790A data associated through the operator crosswalk does not address laundry facilities. A blank or omitted field is not proof that a facility is absent.
- A current lodging listing for the operator-linked, separate Morton property displays a laundry room. This is third-party counterevidence and does not establish conditions at the Pontiac camp.
- The Pontiac camp and operator-linked Morton lodging are separate sites 77.252 km apart. The match is an operator/entity link, not a same-site match.

## Records needed

An actual finding requires the IDPH inspection report/checklist, photographs, deficiency and correction records, reinspection records, complaint file, and permit/license file. The repository includes a draft request at [`IDPH_FOIA_request_migrant_camp_00128.md`](IDPH_FOIA_request_migrant_camp_00128.md). It has not been submitted.

The official Illinois code PDF is preserved at [`Illinois_Migrant_Labor_Camp_Code_Part_935.pdf`](../output/pdf/Illinois_Migrant_Labor_Camp_Code_Part_935.pdf); Section 935.65(d) appears on PDF page 13.
